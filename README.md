# Viaje de la misión — El ladrón del rayo

Prueba de lectura jugable de *El ladrón del rayo* (Rick Riordan) para 6° básico,
asignatura de Lenguaje y Comunicación. El estudiante acompaña a Percy por los diez
lugares de la novela y responde quince preguntas a los personajes.

**Jugar:** https://cifuac.github.io/viaje-de-la-mision/

- Esta es la **versión liviana para el navegador** (unos 470 MB la primera vez; el
  navegador la guarda para las siguientes). Usa el modo gráfico simple de la web, con
  texturas reducidas. La versión completa, en alta calidad, es la de Windows que se
  copia con un pendrive y funciona sin internet.
- Funciona mejor en Chrome o Edge en un computador; no está pensada para celulares.
- Al jugar, el resultado se envía a la planilla del profesor. Para probar sin enviar
  nada, agregar `?profesor` a la dirección:
  https://cifuac.github.io/viaje-de-la-mision/?profesor

Hecho con Godot 4.7. Referencia: Riordan, R. (2006). *El ladrón del rayo*
(L. Aguilera, trad.). Salamandra.
